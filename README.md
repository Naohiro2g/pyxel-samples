# pyxel-samples

[Pyxel](https://github.com/kitao/pyxel)を試すサンプルです。

## 動かし方

[uv](https://docs.astral.sh/uv/)を入れて、このフォルダーで次を打ちます。PythonとPyxelは、uvが`.python-version`と`uv.lock`のとおりに用意します。

```bash
uv run hello_pyxel.py
```

Escで終わります。

何も入っていない機械からの手順（Windows、Linux、macOS）は、[環境構築のrunbook](docs/setup-runbook_ja.md)にあります。

## サンプル

- `hello_pyxel.py`：色が変わる文字と、横へ動く四角
